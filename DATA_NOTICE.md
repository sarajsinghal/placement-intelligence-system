# Dataset notice

The public repository contains application code and empty CSV templates only. Student profiles, resumes, faculty feedback, and other populated datasets are not licensed for redistribution and are excluded from Git with the `data/` ignore rule.

The local `data/` folder is kept on the developer's machine for local demonstration. Do not add its populated files to a public repository. The MIT license in `LICENSE` applies to software code; it does not grant rights to any datasets supplied separately.
